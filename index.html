Notes

Work in progress

A personal study notes app that I am building for myself as a student. Each note is a set of pages with a free-form canvas where text, hand-drawn sketches, images and scanned fragments of paper notes can be placed anywhere.

Planned features

  • Free-form canvas pages with text, drawing (finger, stylus or mouse) and images
  • Works offline as an installable web app (PWA) on Android and desktop
  • Notes are stored in my own private GitHub repository and synced when online
  • Photo import of handwritten notes: text recognition and diagrams cut out as separate image blocks

Technology

  • TypeScript, React, Vite
  • tldraw for the canvas editor
  • GitHub API for storage and sync

This is a strictly non-commercial personal project: it has no ads, payments or user accounts, and it is used only by its author.
