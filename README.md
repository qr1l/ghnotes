# Notes (ghnotes)

Личное приложение для конспектов: холст tldraw с листами, работает офлайн как PWA.
Публикуется на https://qr1l.github.io/ghnotes/

## Запуск у себя

```
npm install
npm run dev
```

Открой адрес из консоли. В режиме разработки ключ tldraw не нужен.

## Публикация

1. Положи содержимое этой папки в репозиторий `ghnotes` (ветка `main` или `lrq`).
2. Settings → Pages → Source: выбери **GitHub Actions**.
3. Settings → Secrets and variables → Actions → вкладка **Variables** → New repository variable:
   имя `VITE_TLDRAW_LICENSE_KEY`, значение — ключ tldraw из письма.
4. Каждый push в `main` или `lrq` пересобирает и публикует сайт (вкладка Actions).

Временный ключ действует до 31 октября 2026. Когда придёт постоянный, просто замени значение переменной и запусти
Actions → Deploy to GitHub Pages → Run workflow.

## Установка на телефон

Открой сайт в Chrome на Android → меню → «Установить приложение». Один раз открой его с интернетом,
чтобы кэш загрузился, после этого холст работает без сети.

## Что уже есть

- Холст tldraw (листы, текст, рисование пальцем, стилусом и мышью, картинки)
- Автосохранение в браузере (IndexedDB), шрифты и иконки встроены для работы офлайн
- PWA: установка, кэш приложения
