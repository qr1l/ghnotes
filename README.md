# Notes (ghnotes)

Личное приложение для учебных конспектов: холст tldraw с листами, работает офлайн как PWA.
Публикуется на https://qr1l.github.io/ghnotes/

Данные хранятся в отдельном приватном репозитории GitHub и синхронизируются через GitHub REST API.

## Запуск у себя

```
npm install
npm run dev
```

Открой адрес из консоли. В режиме разработки ключ tldraw не нужен.

## Установка на телефон

Открой сайт в Chrome на Android → меню → «Установить приложение». Один раз открой его с интернетом,
чтобы кэш загрузился, после этого холст работает без сети.

## Что уже есть

- Холст tldraw (листы, текст, рисование пальцем, стилусом и мышью, картинки)
- Автосохранение в браузере (IndexedDB через Dexie), шрифты и иконки встроены для работы офлайн
- Темы и конспекты: создание, удаление, адаптивный список (один столбец на телефоне, два на широком экране)
- Картинки: сжатие в WebP, SHA-256, хранение в IndexedDB, ссылки `asset:`
- Локальная сессия (камера, текущий лист) хранится отдельно от документа
- Синхронизация с GitHub: push через 10 секунд после правки, при скрытии вкладки, при online; pull при открытии; конфликты создают копию конспекта
- Индикаторы синхронизации в списке и в шапке конспекта
- PWA: установка, кэш приложения, плашка «Доступна новая версия»
- Настройки: токен GitHub, владелец, репозиторий и ветка с проверкой подключения
- Типизированный клиент GitHub REST API (`src/github/api.ts`)
- Hash-роутинг: список, холст, настройки
- Подпись версии сборки (коммит и дата) на экране настроек и внизу списка
